## RetroBit Launcher v2.5.0-retrobit

RetroBit Launcher is a minimalist, Niagara-inspired Android launcher with an e-paper-inspired cyberdeck interface.

### Highlights
- Stealth auto-hiding app list, curved thumb-friendly app layout, and an A–Z scrubber.
- Organize and declutter apps with favorites, category filters, hidden apps, and custom app names.
- Retro cassette-style media controls, notification previews, screen-time telemetry, and a mindful pause before opening distracting apps.
- Four monochrome-inspired themes, an e-paper refresh effect, an inline calculator, and a small cyberdeck terminal.
- Export and restore launcher configuration as JSON.

### Install
Download `app-debug.apk` from the assets below and install it on an Android device (minimum Android 8.0 / API 26; target Android 14 / API 34). You may need to allow installation from your browser or file manager. To use RetroBit as your home screen, select it as the default launcher in Android settings.
